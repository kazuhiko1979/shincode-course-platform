# ハーネス設計ナレッジ（開発の軸）

このディレクトリは、AI エージェント開発を **一過性でなく資産として蓄積・洗練していく**ための永続ナレッジ。
出典は「実践 Claude Code ハーネス設計完全ガイド」（Atsushi Ishida / neh.app、原本 PDF は `docs/` 直下）＝Anthropic 公式エンジニアリング記事群の蒸留。

> **設計哲学：AI の凹みに構造を、でっぱりは安心して任せられるように。モデルが進化しても、設計したハーネス構造は資産として永続する。**

## 使い方（このナレッジをどう回すか）

1. **設計・変更のたびに軸を参照**：新しい Rule/Hook/Skill/サブエージェント/評価を足す前に `01_principles.md` の該当節を見る。
2. **仮説検証で育てる**：「AI が X を自力でできないはず」と仮説を立て、補助（構造）を入れて検証。正しければ組み込み、間違いなら取り除く（`02_maturity.md` のロードマップに反映）。
3. **定期的に前提を見直す**：モデルが進化したら不要になった部品を削りシンプルに保つ。採点日を更新し、成熟度を再評価する。
4. **改善は spec-first**：Hooks/settings 変更や新規部品の追加は `AGENTS.md` の安全ルールに従い、着手前に `docs/` 起票＋人間承認。

> このナレッジ自体が **Write 戦略の実践**（知識の外部永続化）。更新し続けることに価値がある。
